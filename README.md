## Sobre o Projeto

Este repositório contém uma implementação robusta do jogo **Campo Minado**, desenvolvida para aprofundar meus conhecimentos em Java e Programação Orientada a Objetos.

## Como rodar

O projeto segue a estrutura padrão de pacotes Java (`br.com.game`).

1.  **Para jogar/testar a lógica:** Recomendo abrir o projeto em uma IDE (IntelliJ, Eclipse ou VS Code).
2.  **Rodar Testes:** Execute a pasta `test/` via JUnit para validar as regras do tabuleiro.
3.  **Executar:** O método `main` (se disponível) iniciará a interação via terminal.
